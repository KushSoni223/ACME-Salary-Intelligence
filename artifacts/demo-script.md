# Demo Walkthrough

Estimated length: 3 minutes. Start with a freshly seeded local database and both servers running; open `http://localhost:5173`.

1. **Overview (30 seconds):** Point out the 10,000-person population, payroll and median cards, and the selected currency label. Explain that amounts are never combined across currencies.
2. **Pay questions (45 seconds):** Switch the distribution between team and country. Choose a currency filter and show that the averages and top-earner list update within that currency.
3. **Find a person (35 seconds):** Search for an employee ID or name, then filter by country and status. Change the sort using the annual compensation header and move between pages.
4. **Update compensation (35 seconds):** Open a row's compensation action, change salary/effective date, save, and show the updated row and refreshed analytics.
5. **Add a person (30 seconds):** Add an employee using the next unused ID, select department/country/currency, enter salary and effective date, then show the new record.
6. **Export and close (15 seconds):** Export the current page to CSV and mention the API's OpenAPI documentation at `http://localhost:8000/docs`.

Use only synthetic seed data in any recorded demo. Do not record real employee compensation details.
